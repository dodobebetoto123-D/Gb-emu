# GB-EMU — 웹 기반 게임보이 / 게임보이컬러 에뮬레이터 (v0.1)

LR35902 CPU 인터프리터 + 스캔라인 PPU + 타이머/인터럽트/Joypad/APU를
ES 모듈로 구현한 웹 에뮬레이터. GBA는 범위 밖.
부트 롬(BIOS) 없이 CPU 레지스터를 직접 초기화해 부트 과정을 스킵한다.

## 실행 방법

정적 파일 서버로 실행한다 (ES 모듈 `import` 때문에 `file://` 직접 열기는 동작하지 않음).

```bash
cd ~/workspace/gb-emu
npx serve .
# 또는
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:3000` (npx serve) 또는
`http://localhost:8000` (python http.server)으로 접속.

## 조작법

- **롬 불러오기**: "파일 선택" 버튼으로 `.gb` / `.gbc` 파일 선택, 또는 창에 드래그앤드롭.
  롬 파일은 사용자가 직접 구해야 한다 (저작권 경계 — 저장소에 롬을 포함하지 않음).
- **시작 / 일시정지**: "시작" 버튼 토글
- **리셋**: "리셋" 버튼 (부트 스킵 상태로 초기화)
- **키보드**:
  - 방향키: 십자키
  - `Z`: B 버튼, `X`: A 버튼
  - `Enter`: Start, `Shift`: Select
  - 방향키 입력 시 페이지 스크롤 방지됨
- **상태 표시**: 로드된 롬 제목, DMG/GBC 모드 표시

## 테스트용 공개 롬 안내

동작 확인용으로는 공개 테스트 롬을 사용자가 직접 구해서 사용한다.
대표적으로 **Blargg's test ROMs** (CPU 명령어·타이밍·사운드 검증용)가 있다.
다운로드 후 위 "롬 불러오기"로 실행하면 된다.
(저작권 게임 롬은 직접 덤프한 것만 사용할 것.)

## 개발자용 테스트

```bash
cd ~/workspace/gb-emu
node --check js/*.js        # 문법 검증
node js/cpu_test.js         # CPU 단위 테스트 (mock MMU, 184 assertions)
node js/emu_test.js         # 통합 테스트 (합성 테스트 롬으로 120프레임 실행)
```

`emu_test.js`는 합성 테스트 롬(32KB, 0x100에 NOP+JP 0x150, 0x150부터 타일 1개를
VRAM에 써서 화면에 표시 후 무한 루프)을 코드로 생성해 사용하므로 저작권 롬이 필요 없다.
DMG 모드 120프레임 + GBC 모드(CGB 플래그 0x80) 실행을 검증한다.

## 알려진 한계 (v1)

- VRAM/OAM 접근 타이밍 제한 미구현 (언제든 접근 허용).
- APU: 채널1 사각파는 샘플 버퍼 생성까지 구현, 채널2~4는 스터브.
  프론트엔드 오디오 출력 연동은 v2라 현재는 무음.
- HALT 버그는 재현됨. EI 1명령어 지연 등 일부 엣지 케이스는 단순화.
- 세이브 (배터리 RAM 영속화) 미구현.
- 시리얼 통신 미구현.
- 리셋(`Emulator.reset()`)은 CPU/PPU 프레임 플래그만 초기화한다.
  타이머 카운터·MMU HDMA 진행 상태 등은 유지된다 (loadROM 시에는 새로 생성됨).

자세한 모듈 인터페이스 계약은 `DESIGN.md` 참조.
